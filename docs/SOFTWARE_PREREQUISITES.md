## Required Windows Settings

### Developer Mode
You **must enable Developer Mode** on your Windows device. This allows the application to run smoothly without constantly requesting administrative privileges—making it safer and easier for standard or child accounts to use.

#### How to enable Windows Developer Mode:
1. Open your **Windows Settings**.
2. Navigate to **Privacy & security** → **For developers**.
3. Toggle the switch to **On** for **Developer Mode**.
