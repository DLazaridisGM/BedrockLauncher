# Hardware Prerequisites

Your system must meet or exceed the following hardware specifications to ensure stable performance for both the launcher and the game.

---

## Memory & Storage Specifications

| Component | Launcher Requirements | Minecraft Requirements (1 Version) |
| :--- | :--- | :--- |
| **System Memory (RAM)** | 200 MB | 4 GB |
| **Storage** | 125 MB | 200 MB - 3 GB |

---

## Core System Specifications

| Component | Minimum Requirement |
| :--- | :--- |
| **System Architecture** | x64 (64-bit) |
| **Processor (CPU)** | Intel Celeron J4105 or AMD FX-4100 |
| **Graphics (GPU)** | Intel HD Graphics 4000 or AMD Radeon R5 |
