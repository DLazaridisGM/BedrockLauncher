# Developer Software Prerequisites

Before setting up the development environment, ensure you have the required tools and components installed.

---

## Required Software

| Software | Purpose / Edition |
| :--- | :--- |
| **Visual Studio 2026** | Integrated Development Environment (IDE) |
| **Node.js** | JavaScript Runtime |
| **PostSharp** | Community Edition |

---

## Required Visual Studio Workloads & Components

When installing or modifying your Visual Studio 2026 installation through the Visual Studio Installer, ensure the following options are selected:

| Workload / Component | Purpose |
| :--- | :--- |
| **Desktop development with C++** | Required for compiling and building the native C++ components. |
| **.NET Desktop Development** | Required for building, running, and debugging the managed (.NET) application logic. |
